# Roadmap

What's planned, roughly in order. Suggestions are welcome as issues.

## Next
- **Signed, notarised releases** with a download page, and automatic update checks that can be turned off.
- **Website** (static, Cloudflare Pages), designed and kept in `site/`.
- **App icon refresh** from the brand work (the "b" with the amber reading line).

## Later
- **A "Present with Bema" button on PowerPoint's ribbon**, as an Office add-in served from the project website, using the `bema://` link.
- **Google Slides import:** paste a link, sign in with Google, present the latest version through PowerPoint or Keynote. Today: download as PowerPoint (.pptx) and present that.
- **More languages for voice commands and filler words.**
- **Rehearsal history:** compare runs of the same talk over time.

## Ideas
- Pointer packs and custom stamps.
- An audience Q&A queue alongside polls.
- Recording a rehearsal with slide timings for review.
