Bema 0.1.10 steps out of the Dock when you're not using its window.

### Changed
- **Bema is in the Dock only while its window is open.** Close the window and Bema stays in the menu bar, ready for ⌃⌥P, the PowerPoint button and links. Open the window again and it's back in the Dock. With the menu bar icon turned off, Bema always stays in the Dock.
- **Show Bema window** is now the first item in the menu bar menu.

### Fixed
- Opening a deck while Bema's window was closed could load it with no window showing. The window now opens.

### Updating
Bema offers this update automatically within a day, or choose **Bema → Check for Updates…**.
