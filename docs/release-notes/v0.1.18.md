Bema 0.1.18 makes the timer behave when a show ends.

### Fixed
- When a slideshow ends, the timer stops and its time is shown dimmed, no longer in red with *over time*, in the window and the menu bar panel.
- The next slideshow starts the timer from 0:00. Press ▶ on the timer first to carry on from where it stopped.
- Closing Bema's window outside a show clears the timer, so an old talk's time doesn't stay in the menu bar panel or come back with the window.

### Updating
Bema offers this update automatically within a day, or choose **Bema → Check for Updates…**.
